# Kingdom of Ashes Reborn — 0.1 visual prototype
Independent Godot 4 project, compatibility renderer, no browser engine. Open project.godot in Godot 4.4.1 or newer, press F6 on world/world.tscn or F5. WASD or click to move, Space or click goblin to attack, E toggle armor, G toggle gender. No account, saves, quests or online services. 
The map is an adapted FLARE Alpha Demo Frontier Outpost, a licensed visual benchmark, not final original world design. Sprites, map and textures are CC BY-SA 3.0, attribution in assets/classic and assets/imported/SOURCE.md. Only the small prototype is under this branch; original web game stays on main. Assets/imported is generated by the GitHub workflow and committed after tests. Download the workflow artifact or the branch archive after the generated assets commit. Godot engine and .godot cache are not bundled.
